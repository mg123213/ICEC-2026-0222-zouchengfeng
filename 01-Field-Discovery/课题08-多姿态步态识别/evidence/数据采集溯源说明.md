## 三、时间顺序的合理性

采集发生在 16:02 到 16:10 的 8 分钟内，顺序为：

```
16:02 静止  →  16:07 平地慢走  →  16:08 快跑  →  16:10 上下楼梯
```

课题 08 的 README 中写的采集区间是「15:57–16:10」，与截图最早的 16:02 相差 5 分钟，
原因是 15:57 为开始录制前的准备与设备静置，相册截图记录的是四次正式录制的结束时刻。

先测静止（设备平放、确认零漂），再依次测三种运动状态，符合「先标定、后测量」的实验习惯。采集日期 11 月 12 日早于报告撰写日期 11 月 17 日，时间线不存在倒置。

## 四、CSV 的格式特征

四份 CSV 的列名与 Phyphox 导出格式一致：

```
Time (s), Linear Acceleration x (m/s^2), Linear Acceleration y (m/s^2),
Linear Acceleration z (m/s^2), Absolute acceleration (m/s^2)
```

数值为科学计数法（如 `-5.539298058E-3`），保留约 10 位有效数字，且首行全为 `0.000000000E0`——这是 Phyphox 启动后前几个采样点的典型表现，不是手工编排的数据。

## 五、如何复核

任何人可以独立验证上述对应关系，不需要信任本说明：

```bash
# 1. 查看 CSV 的极值，与截图的纵轴量程比对
python -c "
import csv
for name in ['01_静止','02_平地慢走','03_快跑','04_上下楼梯']:
    with open(f'raw_data/{name}_原始波形.csv', encoding='utf-8-sig') as f:
        rows = list(csv.DictReader(f))
    for axis in 'xyz':
        vals = [float(r[f'Linear Acceleration {axis} (m/s^2)']) for r in rows]
        print(name, axis, round(min(vals), 3), round(max(vals), 3))
"

# 2. 查看截图元信息（相册详情页已直接展示文件名、设备、大小、路径）
#    evidence/phone_album/05~08_*_album_detail.jpg 中可见
```

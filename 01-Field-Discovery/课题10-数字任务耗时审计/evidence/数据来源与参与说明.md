# 课题 10 数据来源与本人参与说明

> 目的：说明本课题的输入数据从哪来、本人参与在哪些环节、哪些数字是实测、哪些是估算。
> 结论先写在前面：**样本数据与本人实测强相关（哈希可核），AI 耗时是脚本实测，人工耗时目前是估算值**——这一点如实标注，不粉饰。

---

## 一、输入数据从哪来

`samples/` 下的 10 份 CSV 不是从网上找的公开数据集，而是由**本人课题 08 实地采集的原始波形**派生。

`samples/_source/` 保存了四个源文件，与课题 08 的 `raw_data/` **逐字节一致**，可用 SHA-256 独立核验：

| 文件名 | SHA-256（前 16 位） | 与课题08 同名文件 |
|---|---|---|
| `01_静止_原始波形.csv` | `03ae3a0a7b8fdfda` | ✅ 完全一致 |
| `02_平地慢走_原始波形.csv` | `f9a428926d9bab57` | ✅ 完全一致 |
| `03_快跑_原始波形.csv` | `9d0a93f2116db18f` | ✅ 完全一致 |
| `04_上下楼梯_原始波形.csv` | `930ef31340f47a1b` | ✅ 完全一致 |

核验命令：

```bash
cd 01-Field-Discovery
sha256sum 课题08-多姿态步态识别/raw_data/0*.csv 课题10-数字任务耗时审计/samples/_source/*.csv
```

这条链意味着：课题 10 的每一个样本，都能追溯到课题 08 里某一次具体的手机采集（含设备 AAK-AN00、Phyphox 采集、11 月 12 日 16:02~16:10 的时间戳）。数据溯源材料见
[`../../课题08-多姿态步态识别/evidence/数据采集溯源说明.md`](../../课题08-多姿态步态识别/evidence/数据采集溯源说明.md)。

## 二、十个样本是怎么造出来的

`make_samples.py` 把四份源波形切段、加扰动，生成 10 份「格式各异」的 CSV，刻意复刻真实数据里常见的脏数据问题：

| 问题类型 | 做法 | 涉及样本 |
|---|---|---|
| 时间单位混用 | 部分样本用 `ms` 而非 `s` | S03、S07、S10 |
| 加速度单位混用 | 部分样本用 `g` 而非 `m/s²` | S02、S05、S07、S09 |
| 空行 | 随机插入空行 | S01~S10 均有 |
| 重复行 | 复制相邻行 | S02、S03、S05、S06、S08、S09、S10 |
| 备注行 | 插入非数据文字行 | S02、S04、S05、S06、S09、S10 |

具体分布见 `out/样本清单.csv`，逐文件列出样本数、原时间单位、原加速度单位、空行数、重复行数、备注行数和问题合计。

## 四、哪些是实测，哪些是估算（如实说明）

| 数据 | 性质 | 依据 |
|---|---|---|
| 样本 CSV | **派生自本人实测** | SHA-256 与课题08 raw_data 一致 |
| AI 脚本耗时 | **实测** | `out/耗时_AI.csv`，7 次重复运行，中位数 0.9894 s；`out/run.log` 记录了 `time=2026-11-12 17:37:19`、脚本与输入哈希、总耗时 76.3 ms |
| 人工耗时 | **估算** | `out/人工耗时_估算.csv` 的「数据来源」列明确写「估算」，累计 728.37 s |

**关于人工耗时的说明**：`manual_timer.py` 是为此设计的秒表工具（逐样本计时、首样本作热身不计入、可提前结束按均值外推），但当前仓库中的 10 个数值是按 SOP 步骤数和工作量**推算**的，不是逐次按秒表记录的结果。「数据来源」列已如实标注为「估算」，报告中亦未将其表述为实测。

如果评审要求人工耗时为实测，可用 `manual_timer.py` 补测 3~5 个样本（脚本会按均值外推剩余），再把结果替换进 `out/人工耗时_估算.csv` 并重跑 `compare.py` 更新对比表。

## 五、复核命令

```bash
cd 01-Field-Discovery/课题10-数字任务耗时审计

# 1. 核验样本与课题08 源数据同源
sha256sum samples/_source/*.csv ../课题08-多姿态步态识别/raw_data/0*.csv

# 2. 查看 AI 耗时的原始测量记录
cat out/耗时_AI.csv
cat out/run.log

# 3. 重跑 AI 批处理（会刷新 out/ 下的结果）
python batch.py

# 4. 查看四层校验是否全部通过
cat out/校验明细.csv
```

## 七、局限说明

- 人工耗时是估算而非秒表实测，这是本课题目前最容易被质疑的一点，已在第四节如实写明。
- 样本是在真实波形基础上加工而成，用于制造可复现的脏数据场景；它不是十次独立的真实采集。
- 上述两点都不影响「AI 批处理比人工快数百倍」这个量级结论，但会影响精确倍数的可信度。

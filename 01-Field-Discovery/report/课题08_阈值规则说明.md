# 课题 08：多姿态步态加速度特征采集与对比
## —— 区分动作的阈值规则

> 数据源：Phyphox 1.2.0「加速度（不含 g）」导出（`*Raw Data.csv`）
> 设备：HONOR AAK-AN00 / Android 16，STMicro lsm6dso 加速度计
> 采样率：**208.2 Hz**（dt = 4.803 ms），单段 10 s 左右，2000+ 样本
> 采集时段：2026-11-12 15:57–16:10，同一设备、同一次实验连续完成

## 一、原始波形在说什么

四段数据放进同一坐标尺度后（图 1），形态差异非常直观：

| 状态 | x 轴（侧向） | y 轴（前后） | z 轴（竖直） | 直观印象 |
|---|---|---|---|---|
| 静止 | ±0.05 | ±0.10 | ±0.05 | 纯传感器底噪，无节律 |
| 平地慢走 | ±3 弱 | ±3 强 | +4.9 / −2.7 | 平滑正弦，节律约 1.5 Hz |
| 上下楼梯 | ±5.9 | ±5.2 | +11.3 / −5.3 | 竖直冲击变尖，前后摆幅加大 |
| 快跑 | ±16.7 | ±11.9 | +23.5 / −13.5 | 尖峰密集，落地冲击陡峭 |

三条可用的定性线索：

1. **幅度**：静止（10⁻² 量级）与运动（10⁰ 量级）差两个数量级，这条界线毫无争议。
2. **节律**：慢走是连续平滑的摆动；楼梯与快跑都出现**尖锐的脉冲**，但两者的峰值高度重叠（楼梯最高 11.3，快跑最低段也在 10 以上）。
3. **频率成分**：慢走的能量集中在 1–2 Hz 基频；落地冲击会在 2–8 Hz 拖出大量高频能量。这一条是后面区分楼梯与快跑的关键。

> 结论：单看"幅度"只能把静止切出来，慢走 / 楼梯 / 快跑的幅值区间互相咬合，
> **必须引入对"冲击陡峭程度"敏感的特征**。

## 二、两个特征量

在 2 s 滑窗（步长 0.5 s）内计算：

```
瞬时合加速度   a(t) = √(x² + y² + z²)                       [m/s²]
加速度均方根   RMS(A) = √( mean( a(t)² ) )                    [m/s²]
加加速度       J(t) = da/dt ≈ Δa · f_s                        [m/s³]
加加速度均方根 RMS(J) = √( mean( J(t)² ) )                    [m/s³]
```

- **RMS(A)** 刻画"动得多剧烈"——区分静止与运动。
- **RMS(J)** 刻画"动得多急"——它是一次**微分**，对台阶式突变（脚落地那一瞬）极其敏感。
  慢走是低频正弦，斜率小；楼梯与快跑每步都有硬着陆，斜率陡。
  这就是为什么同样的峰值高度下，两者的 RMS(J) 能差 3 倍以上。

### 特征实测值（整段 10 s）

| 状态 | RMS(A) m/s² | 峰值 a m/s² | P99 a m/s² | **RMS(J) m/s³** | x_std | y_std | z_std |
|---|---|---|---|---|---|---|---|
| 静止 | 0.024 | 0.10 | 0.05 | **2.6** | 0.013 | 0.015 | 0.013 |
| 平地慢走 | 2.235 | 5.25 | 4.64 | **22.9** | 0.849 | 1.309 | 1.584 |
| 上下楼梯 | 3.821 | 11.74 | 8.95 | **65.9** | 1.146 | 1.719 | 3.195 |
| 快跑 | 8.341 | 27.70 | 23.19 | **146.8** | 3.824 | 4.464 | 5.826 |

### 2 s 滑窗的取值范围（这是阈值真正的依据）

| 状态 | 窗数 | RMS(A) 范围 | RMS(J) 范围 |
|---|---|---|---|
| 静止 | 18 | 0.022 – 0.029 | 2.4 – 2.9 |
| 平地慢走 | 17 | 1.55 – 2.86 | 19.8 – 26.7 |
| 上下楼梯 | 18 | 3.04 – 4.36 | 45.8 – 84.3 |
| 快跑 | 17 | 5.41 – 11.53 | 118.2 – 187.7 |

**为什么不能只看 RMS(A)**：慢走上界 2.86 与楼梯下界 3.04 只差 **6%**，
阈值必须卡在 2.95±0.09 之间，传感器噪声、佩戴方式一变就翻车。
换到 RMS(J)：26.7 → 45.8，间隙一下子拉到 **71%**，阈值可以放在中间还两头都留 30%。

### 候选特征筛选：为什么最后落在 RMS(J)

要能用"一条条阈值"切开，特征必须满足一个硬条件：**四类的取值区间按动作强度单调排列、互不重叠**。
否则无论阈值取多少，总有两类会串在一起。把十几个候选特征在 2 s 窗上逐一算过，有代表性的 9 个如下：

| 候选特征 | 四类单调 | 最小类间间隙 / 总跨度 |
|---|---|---|
| **RMS(J) 加加速度均方根** | ✅ | **0.091** |
| 峰值 a（max） | ✅ | 0.021 |
| RMS(A) | ✅ | 0.016 |
| P99 a | ✅ | 0.012 |
| P95 a | ✅ | 0.003 |
| 峰均比 crest、z 轴峭度、高频能量占比、步频 | ❌ 非单调 | — |

（"最小类间间隙 / 总跨度"= 相邻两类里最窄的那个间隙 ÷ 特征的整体跨度，越大越好分开。）

> 本表由 `scripts/screening.py` 生成，原始输出见 [`表3_候选特征可分性.csv`](表3_候选特征可分性.csv)，
> 可自行重跑核对。

后四个**直接淘汰**——它们的类间顺序是乱的：z 轴峭度中位数依次是
「慢走 −0.72 < 楼梯 −0.58 < 静止 0.18 < 快跑 0.37」，静止整整齐齐夹在中间，
一条阈值无论取多少都切不出"相邻两类"。剩下的五个单调特征里，
RMS(J) 的归一化间隙比第二名大 4 倍以上，所以最终只用它。

这也解释了第一节的直觉为什么成立：**峰值、RMS 都在量"幅度"，jerk 在量"斜率"**，
而慢走与楼梯的差别恰恰不在幅度上，在落地那一下有多陡。

一步到位的反面例子记在
[`03-AI-Collaboration/2026-11-12_步态阈值定标.md`](../../03-AI-Collaboration/2026-11-12_步态阈值定标.md)：
先后试过"整段 FFT 主频""单点峰值""z 轴标准差"，都因为区间重叠或对噪声太敏感被否掉。

## 三、阈值规则（核心结论）

```
输入：一段 2 s 的三轴线性加速度（208 Hz）
│
├─ RMS(A) < 0.20 m/s²  且  RMS(J) < 8      → 静止
│
├─ RMS(J) < 35                             → 平地慢走
│
├─ 35 ≤ RMS(J) < 100                       → 上下楼梯
│
└─ RMS(J) ≥ 100                            → 快跑
```

### 阈值与安全裕度

| 判据 | 阈值 | 下侧最近实测值 | 上侧最近实测值 | 裕度（下/上） |
|---|---|---|---|---|
| RMS(A)：静止 / 运动 | **0.20 m/s²** | 0.029（静止） | 1.55（慢走） | ×6.9 / ×7.7 |
| RMS(J)：慢走 / 楼梯 | **35 m/s³** | 26.7（慢走上限） | 45.8（楼梯下限） | +31% / +31% |
| RMS(J)：楼梯 / 快跑 | **100 m/s³** | 84.3（楼梯上限） | 118.2（快跑下限） | +19% / +18% |

### 阈值怎么算出来

三个阈值不是试凑的，统一取**相邻两类边界的几何中点**——在 log 尺度上等距，
这样低类往上、高类往下的相对余量天然相等：

```
阈值 = √(低类实测上限 × 高类实测下限)          ← 几何平均，对倍率敏感、对绝对差免疫

静止 / 运动   √(0.029 × 1.549) = 0.212  → 取 0.20   m/s²
慢走 / 楼梯   √(26.72 × 45.80) = 35.0   → 取 35     m/s³
楼梯 / 快跑   √(84.32 × 118.16) = 99.8  → 取 100    m/s³
```

为什么不用算术平均？因为这几组量的跨度是**倍率级**的（2.4 → 188，近 80 倍）。
算术平均会被大数拽偏，几何平均才能保证"低类还差几成、高类还差几成"对称。

### 规则背后的物理含义

| 判决 | 物理状态 | 判据实质 |
|---|---|---|
| 静止 | 手机没动 | 合加速度只剩底噪（10⁻² 量级） |
| 平地慢走 | 重心平稳前移，单脚支撑期长 | 低频摆动，**无硬冲击** → J 小 |
| 上下楼梯 | 每步都要克服一个台阶落差 | 有明确落地冲击，但**步幅短、冲击间隔长**，J 中等 |
| 快跑 | 有腾空期，落地冲击接近 2 g 以上 | 冲击又高又密 → J 最大 |

## 四、规则验证

以 2 s 窗、0.5 s 步长把 4 段数据切成 **70 个窗口**，逐窗套用上面的规则：

| 真实状态 | 判为静止 | 判为慢走 | 判为楼梯 | 判为快跑 | 准确率 |
|---|---|---|---|---|---|
| 静止 | **18** | 0 | 0 | 0 | 100% |
| 平地慢走 | 0 | **17** | 0 | 0 | 100% |
| 上下楼梯 | 0 | 0 | **18** | 0 | 100% |
| 快跑 | 0 | 0 | 0 | **17** | 100% |

**总体 70/70 = 100%**（图 4 可逐窗核对）。

### 窗长敏感性

| 窗长 | 准确率 | 说明 |
|---|---|---|
| 1.0 s | 76/78 = **97.4%** | 快跑首尾各 1 个窗被判成楼梯 |
| **2.0 s** | **70/70 = 100%** | 推荐工作窗长 |
| 4.0 s | 全对，且边界更宽 | 慢走上限降到 24.1，快跑下限升到 143（裕度 +43%），但延迟大 |

1 s 窗的两个误判出现在 **t=0 s（起跑加速）与 t=9 s（收尾减速）**：
这两段 RMS(A)=4.2/4.5、RMS(J)=64/65，确实落在"楼梯"区间里——
不是算法错了，而是这两个窗口里受试者**真的处在两种动作的过渡态**。
处理办法：判定加 3 帧滑动投票（或 0.5 s 滞后），过渡段就不会跳变。

## 五、使用限制

1. **RMS(J) 与采样率绑定**。J = Δa·f_s，换到 100 Hz 采集，同样的动作 RMS(J) 会变成 208 Hz 下的约 1/2。换设备必须重新标定阈值。
2. **阈值依赖佩戴位置**。本数据为同一放置方式连续采集；若改到裤兜 / 手持 / 上臂，幅值会整体缩放，建议按"静止段的 RMS(A) 中位数 ×N"做自适应归一。
3. **样本量**：单人、单次、每状态 10 s。楼梯/快跑边界（±18%）是最窄的一条，不同受试者、不同楼层坡度可能越界。工程上建议加一条**辅助确认**：2–8 Hz 高频能量占比（快跑中位数 0.97，楼梯 0.71），单窗虽有交叠，但连续多窗取中位数后可把边界再拉开一档。
4. **不能用单点峰值做判据**。快跑峰值 27.7 与楼梯 11.7 差距看着大，但单点峰值受一次抖动影响极大；用 2 s 窗的 RMS 才稳。

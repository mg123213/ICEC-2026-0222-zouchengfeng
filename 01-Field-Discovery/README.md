# 阶段一 · Field Discovery

> 课题 08：多姿态步态加速度特征采集与对比

## 这一阶段做了什么

1. **采集**：用 HONOR AAK-AN00 手机 + Phyphox「加速度（不含 g）」通道，
   分别记录静止、平地慢走、快跑、上下楼梯四段数据，每段约 10 s。
2. **观察**：把四段波形放到同一坐标尺度下对比，找出可量化的差异。
3. **提炼**：把 9 个候选特征算一遍可分性，只在"四类单调且区间不重叠"的特征里挑，
   最终选定加加速度 RMS(J)，据此定出三条阈值。
4. **验证**：用滑窗切分逐窗判定，统计准确率与边界裕度。

  UTF-8 BOM 中文表头，Excel 双击直接开。

## 一句话结论

> 只看"动得多大"分不开慢走和楼梯，改成看"动得多急"（jerk）之后，
> 四类在 `RMS(J)` 上单调排开：2.6 → 22.9 → 65.9 → 146.8 m/s³。

细节、阈值裕度和限制条件见主报告。

## 两个课题的关系

不是拼在一起的两个作业，它们之间有数据依赖：

```
课题08 采集的四段原始波形
  01_静止 / 02_平地慢走 / 03_快跑 / 04_上下楼梯
        │
        ├──> 直接分析 ──> 阈值规则（课题08 的结论）
        │
        └──> 切段 + 注入三类脏数据 ──> 10 个任务样本 ──> 人机耗时对比（课题10）
```

原始数据在 [`课题08-多姿态步态识别/raw_data/`](课题08-多姿态步态识别/raw_data/)，
课题 10 复制了一份到 [`课题10-数字任务耗时审计/samples/_source/`](课题10-数字任务耗时审计/samples/_source/)。
两份内容逐字节一致。

## 各自看什么

**课题 08 —— 一个信号处理问题**

四类动作在幅值类特征上分不开（慢走上界 2.86 / 楼梯下界 3.04，只差 6%）。
换到加加速度的均方根 `RMS(J)` 之后间隙拉到 71%，三条阈值就落得下笔了。
重点看 [`report/课题08_阈值规则说明.md`](课题08-多姿态步态识别/report/课题08_阈值规则说明.md)
里的"四步提炼链路"。

**课题 10 —— 一个工程判断问题**

同样一批数据，人工 12 分钟、AI 0.99 秒。但真正值得看的是反例：
用 `pd.read_csv` 默认参数处理分号分隔的样本，**列数变成 1、峰值只剩 1/9.8，
而且一次异常都不抛**。所以这个课题交付的不是"AI 很快"，而是一套四层校验规则
（输入 / 处理 / 输出 / 追溯）和熔断条件。

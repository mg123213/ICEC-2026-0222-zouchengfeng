## 一、反馈怎么产生

反馈只能通过线上工具的「使用反馈」页提交，没有后台手填入口：

1. 打开线上版 <https://wbapp-b57fhwpr7sd7umxxjlmtff.app.workbuddy.host/?sharecode=CUQ24FLKNH>
2. 用**本人学号**注册并登录（首次需注册，密码至少 6 位且含数字和字母）
3. 切到「使用反馈」标签，选评分、勾选有用的功能、写一句真实感受，提交
4. 记录写入线上数据库，并同步到仓库 `src/feedback/responses.jsonl`

每条反馈都带三样东西：**提交学号、提交时间、评分与原文**。这三样构成可核验的最小证据。

## 二、怎么核验是真实用户

| 核验点 | 怎么看 |
|---|---|
| 学号是否真实 | 学号为本人真实学号，非连号、非顺序段；`2026999xxx` 这类明显虚构的段不采纳 |
| 提交时间是否分散 | 真实反馈来自不同人不同时间，不会集中在同一两分钟内 |
| 内容是否各异 | 真实反馈的措辞、关注点、评分各不相同，不会整段雷同 |
| 账号是否唯一 | 一个学号只算一位用户，同一账号重复提交只取一条 |
| 能否对上后台记录 | 线上管理后台 `/admin` → 使用反馈，可逐条对照学号与时间 |

## 五、为什么不凑数

作业要求是「8 位真实用户使用反馈」，关键词是**真实**。用批量生成的账号和雷同文案凑到 8 条，形式上达标，但只要评审核对学号段与提交时间就会发现，反而会让整份作业的可信度受质疑——包括那些真实做过的部分。宁可如实写「已收 2 条，正在补」，也不拿假数据充数。

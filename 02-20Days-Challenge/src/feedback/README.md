# 用户反馈

## 数据文件

`responses.jsonl` —— 一行一条，由程序「使用反馈」标签页写入，也可手工追加。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ts | string | 提交时间（精确到分钟） |
| role | string | 身份：班长 / 学习委员 / 普通同学 / 实训室管理员 / 班主任 / 其他 |
| score | int | 1–5 分 |
| useful | string[] | 实际用上的功能 |
| comment | string | 文字反馈（≤300 字） |
| would_use | bool | 是否愿意继续用 |

**不收集**姓名、学号、手机号、微信。需要署名的话由本人写在 comment 里，自行决定。

## 收集流程

见 `docs/用户反馈收集说明.md`。

## 生成汇总

```bash
python tools/export_feedback.py
```

输出 `docs/用户反馈汇总.md`：评分分布、身份分布、功能使用率、逐条原文。

## 手工补录格式

没法当场用网页提交的（比如在实训室口头给的反馈），按下面格式追加一行：

```json
{"ts":"2026-11-18T14:20","role":"实训室管理员","score":4,"useful":["器材核对","催还话术"],"comment":"核对比手工快，但借出表没有应还日期时算不出超期","would_use":true}
```

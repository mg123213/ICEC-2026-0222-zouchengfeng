不是 diff 片段 —— 想复现哪一版，进目录直接 `python app.py` 就能跑。

选择依据只有一个：**上一版留下的问题被日志或评测抓到了**，才开下一版。

## v3_时间区间与起始语

`356da71` · 2026-11-17 00:47

这一版解决的是**最危险的一类错误**：把开始时间当截止时间，用户会照着错误日期准备。

- 扫描相邻时间候选之间的连接符（`至/到/—/~/～`），把前者标记为区间起点、后者为终点
- 起点减 0.50 分，终点加 0.15 分
- 支持 `24:00`，按当日 23:59 处理
- 三类负向语义：起始语（`自…起`）、活动安排语（`定于…举行`）、区间起点。
  附近 15 字内没有「截止/不晚于/请于」等强锚点时，直接剔除该候选；全被剔除就返回 `None`

还修了一个隐蔽的定位错误：判断上下文时用的是"绑定时刻之后"的位置，导致
`11月20日起` 里的「起」被跳过、08 号用例一直修不掉 —— 改用日期本身的结束位置。

截止 62.5% → 100%。

## v5_线上部署适配

`9c4ebc6` · 2026-11-17 01:03

发布到线上后页面**没有任何样式**。原因是平台网关要求每个请求都带 `sharecode`，
而浏览器发起的 `<link>` / `<script>` 不会自动带主页面的查询参数，全部 403。

更麻烦的是网关转发前会把 `sharecode` 从 query 里剥掉，服务端读不到。
最终方案：云端模式把 CSS/JS **内联进 HTML**，整页只有一次请求；后续 fetch 由前端
从 `location.search` 取 `sharecode` 自行拼接。

同时加了按 `PORT` 环境变量切换监听地址（云端 `0.0.0.0` / 本机仍只绑 `127.0.0.1`）。

排障过程见 `../../03-AI-Collaboration/`。

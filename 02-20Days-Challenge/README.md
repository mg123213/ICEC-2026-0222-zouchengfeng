## 目录约定

```
02-20Days-Challenge/
├── src/              # 源码。按天或按功能分子目录，能跑起来为准
├── process_logs/     # 每日过程日志，一天一个文件：YYYY-MM-DD.md
└── iterations/       # 迭代留档。v1_初版/ v2_加xxx/ …，只留能跑的版本
```

**三条规矩**（避免后期翻不出东西）：

1. **日志当天写**。写"今天卡在哪、怎么绕过去的"，不写流水账；
   代码能复现结论，但复现不了当时的判断过程。
2. **迭代不覆盖**。改版就新开一个 `iterations/vN_说明/`，别把上一版删掉——
   最后复盘时"从 v1 到 v4 改了什么"比"v4 长什么样"更有价值。
3. **`src/` 必须是能直接跑的**。依赖写进 `src/requirements.txt`，
   跑不通的半成品放 `iterations/` 里，别混在 `src/`。
